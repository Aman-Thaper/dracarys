DRACARYS

Attack. Prove. Fix. Retest.

An evidence-first DAST scanner. Every finding is confirmed by a deterministic oracle plus captured request/response evidence — the language model never decides what counts as a vulnerability.

Install

# CLI
pipx install dracarys-dast

# scan a local app — loopback needs no authorization flag
dracarys scan http://127.0.0.1:3000

# an authorized target: SARIF + HTML, fail CI on high severity or above
dracarys scan https://staging.example.com --yes-i-am-authorized \
  --sarif out.sarif --html report.html --fail-on high

Proof it generalizes

1.0recall on independent testbed apps
0false positives on the hardened control
80tests, ~85% coverage
8detector classes, all CWE-mapped

These are not claims about the bundled demo. dracarys scan-selftest runs the scanner against independent vulnerable applications it was not tuned on, plus a hardened control app, and scores the result against ground truth. It runs on every CI build.

The differentiator: verified remediation

1 · Prove

Exploit the finding against the running target and capture the evidence — paired baseline and attack exchanges, hashed and redacted.

2 · Fix

Generate a remediation, then rebuild the target with the patch applied.

3 · Retest

Replay the original attack against the patched build. It reports FIX VERIFIED only when the exploit actually stops working.

In your pipeline

- id: scan
  uses: Aman-Thaper/dracarys@v0.1.1
  with:
    target: http://localhost:3000
    fail-on: high

- if: always()
  uses: github/codeql-action/upload-sarif@v3
  with:
    sarif_file: ${{ steps.scan.outputs.sarif-file }}

Findings land in the GitHub Security tab as SARIF 2.1.0. Reports also render as HTML, JSON, Markdown, or a terminal table, and --fail-on sets the exit code.

Also available as

MCP server

Give an agent the scanner. pip install "dracarys-dast[mcp]" then claude mcp add dracarys -- dracarys-mcp. The authorization gate still applies — an agent cannot point it at an arbitrary host on its own.

HTTP API

POST /api/scan runs a scan behind the same policy engine, for wiring DRACARYS into an existing platform.

Honest scope

What it is: a real but early-stage lightweight DAST — evidence-first, low false positives, SARIF/CI-native, with verified-fix retesting. What it is not: a Burp or ZAP replacement. Coverage is the core eight classes above; SSRF, CSRF, path traversal and SSTI are not implemented yet.

Authorization: payloads are non-destructive by contract — read-only SQL, benign markers, short sleeps. Loopback targets scan freely; any other host is refused unless you explicitly assert you are authorized to test it. Only scan systems you have permission to test.
